## 另一台电脑安装步骤

1. 停止客服接待，关闭旧程序，保留旧安装包。
2. 备份该电脑的 `%LOCALAPPDATA%\XianyuAssistant` 目录，尤其是数据库、日志与恢复凭据。数据库备份应在程序关闭后复制。
3. 安装 0.1.5。安装种子数据仅用于不存在数据库的新环境；已有电脑使用其原有数据。首次升级旧数据库时另存 `data` 目录下的 `backups\before-0.1.5.db`，此处 `data` 指应用数据库所在目录。
4. 确认客服设置、价格和话术；已有配置沿用。安装程序不打包 API Key；已有电脑通常继续使用本机凭据。
5. 启动调试浏览器，检查本机 CDP 端口，再启动客服接待。暂时断连会显示恢复状态；长期未连接、验证码或登录失效会保留明确原因。
6. 保留现有人工事件。发送不确定的顾客先核对平台聊天记录，再使用现有“已处理，恢复该顾客”。售后、发货、人工主动接管等锁不批量清除。

## 真实测试观察与回传

建议先小范围运行 24–48 小时，按实际消息量决定覆盖范围。观察正常回复是否持续推进、单个顾客故障是否影响其他顾客，以及浏览器恢复后是否重复发旧消息。

如再次停止回复，先记下客服接待状态、当前阶段与时间，导出客服对话质检 ZIP。包内 `send_attempts.jsonl`、`send_recovery.jsonl`、`runtime.json`、`fault_log.txt`、`failure_summary.json` 用于关联提交、回读、故障和运行；可在现有导出选项中决定是否包含原文。无需单独拷贝 API Key。

若出现重复发送、价格错误、人工状态被误解除，停止接待并立即导出现场。回退时保留新版本数据库与日志，使用旧安装包配套的安装前备份；不要直接用旧程序写入未经确认兼容的新数据库。
