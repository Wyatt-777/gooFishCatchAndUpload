## 二、今天完成的工作

### 1. 修正采集数据来源

此前程序只解析搜索结果卡片，导致以下问题：

- 搜索卡片的标题可能其实是详情文案摘要；
- 搜索卡片价格可能是活动价、参考价或不完整价格；
- 详情页独立显示的属性规格没有被保存。

现已改为：

1. 搜索页只用于发现商品链接；
2. 逐条打开商品详情页；
3. 从详情页读取售价、完整“宝贝描述”、详情图片和属性规格；
4. 全部详情读取成功后才将任务标记为完成并保存。

相关代码：

- `src/xianyu_assistant/crawler/xianyu_crawler.py`
- `src/xianyu_assistant/crawler/xianyu_detail_parser.py`

### 2. 调整“标题/描述”模型

用户确认当前闲鱼发布页没有独立标题输入框，商品信息应统一写入“宝贝描述”。

- 数据库中的 `title` 现在只承担列表摘要用途；
- 详情页完整文案保存至 `description`；
- 发布确认窗口已移除标题输入及“标题合并到描述”的旧逻辑；
- 发布页只填入经过用户确认的“宝贝描述”。

相关代码：

- `src/xianyu_assistant/ui/publish_dialog.py`
- `src/xianyu_assistant/publishing/xianyu_publisher.py`

### 3. 新增属性规格采集与保存

新增 `ProductAttribute(name, value)` 数据模型，并新建 SQLite 表 `product_attributes`。

已能够采集并展示例如：

- `品牌：SENSAH`
- `成色：明显使用痕迹`
- `类型：前拔`

产品表格已从“分类”列改为“属性规格”列；Excel 导出新增“属性规格”列。

相关代码：

- `src/xianyu_assistant/domain/models.py`
- `src/xianyu_assistant/persistence/sqlite_repository.py`
- `src/xianyu_assistant/ui/product_table.py`
- `src/xianyu_assistant/export/excel_exporter.py`

### 4. 修正价格采集与预填规则

详情页现在以醒目售价区域为唯一来源。

- 单价示例：`¥2599`、`¥25`；
- 区间价示例：`¥1399 - 2599`、`¥25 - 246.8`；
- 区间价会原样保存，绝不擅自取最低价或最高价；
- 区间价不能直接写入发布页价格框，程序会提示用户在确认窗口填写一个明确发布价后重试。

### 5. 发布页属性规格顺序与安全边界

发布预填顺序固定为：

1. 填写宝贝描述；
2. 上传本地图片；
3. 填写单一价格；
4. 等待闲鱼动态生成属性规格控件；
5. 仅对“属性标签”和“选项值”都完全匹配的属性进行选择。

分类不会自动选择，最终“发布”按钮也从未被程序点击。

真实样本验收（本地商品 ID `56`）：

- 上传图片：2/2；
- 描述与价格：已成功写入；
- 自动完成：`成色：明显使用痕迹`、`类型：前拔`；
- 保留人工处理：`品牌：SENSAH`，因为“自行车变速器”分类的品牌选项中不存在完全一致的 `SENSAH`，程序没有猜测替代品牌。

发布工作线程的完成提示会显示“已填属性数量”和“需手动选择数量”。

- `src/xianyu_assistant/services/publish_worker.py`

## 四、已知限制与未解决项

1. **品牌并非总能自动填入。**
   闲鱼发布页给出的品牌选项受分类限制；若采集值不在选项中，必须人工选择或保留为空。当前策略是安全优先，不做近似匹配。

2. **区间价必须人工定价。**
   这属于商品本身多规格价格表达，不能自动转换为某一个发布价格。

3. **分类仍需用户确认。**
   这是既定安全边界，避免错误发布到不匹配类目。

4. **动态网页选择器存在维护成本。**
   闲鱼页面类名虽按语义前缀匹配，但若页面大改，可能需要更新 `xianyu_detail_parser.py` 或 `xianyu_publisher.py`。

5. **发布流程的 UI 端到端点击尚可再补一次。**
   已通过真实 `XianyuPublisher` 的浏览器预填验收，也已重启最新版桌面程序；建议后续从任务 3 中选择本地商品 ID 56 对应的“顺泰retrospect…”商品，点击“发布辅助”，确认桌面窗口状态栏正确显示“已填 2 项属性，另有 1 项需手动选择”。不要点击闲鱼最终发布按钮。

6. **尚未进行 Phase 7。**
   还未完成 PyInstaller 正式打包、干净 Windows 环境验收、用户安装说明和日志/清理入口。

7. `README.md` 的阶段说明仍可更新，使其反映详情页采集和属性规格能力。
