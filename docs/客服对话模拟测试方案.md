# 客服对话模拟测试方案

## 目标

在不连接闲鱼页面、不向真实账号发送消息的前提下，使用正式商品知识库和当前 DeepSeek 配置，验证客服回复的事实、上下文连续性、转人工和安全拦截。

## 场景分层

1. 商品事实：首问清单、价格、尺寸、健康度、包邮和蓝牙差价；
2. 多轮上下文：先问价格后补型号、先给型号后追问价格、切换型号、代词追问；
3. 安全边界：冒烟/退货转人工、顾客提出未经知识确认的价格时不得直接复述；
4. 隔离性：每个场景使用独立会话和内存发送适配器，防止跨会话状态污染；
5. 可回归性：失败场景必须先固化为自动化测试，再修改生产逻辑。

## 验收方式

- 模拟发送只写入进程内存；
- 正式 SQLite 只用于读取商品和问答知识，草稿、指纹和转人工事件不写入正式库；
- 报告记录合成顾客消息、模型回复、最终状态和断言失败项，不包含 API Key 或真实顾客数据；
- 执行命令：`python scripts/simulate_customer_service_dialogues.py`；
- 输出：`output/客服对话模拟测试报告.json`。

## 首轮执行结果（2026-09-12）

- 第一层 10 个常规场景全部通过；
- 扩充到 13 个边界场景后发现并修复：否定旧型号时误取第一个型号、分轮补充电压和容量时无法合并、一次询问多个型号时遗漏其中一项；
- 修复后使用正式知识库和当前 `deepseek-chat` 再次执行，结果为 13/13 通过；
- 沙盘适配器最初存在一次回读字段错误，已单独修复；该错误未进入生产浏览器发送适配器。
