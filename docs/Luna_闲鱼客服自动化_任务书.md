# Luna：闲鱼客服自动化实施任务书

## 首要指令

完整阅读并严格执行：

- `docs/闲鱼客服自动化_V1_实施方案.md`
- `闲鱼铺货助手_Codex开发指南.md`
- `docs/卖家主页工作流架构.md`

不要一次性完成全部客服功能。严格按 `CS-0` 到 `CS-6` 分阶段实施；每一阶段开始前先向用户说明：本阶段目标、设计理由、涉及文件、实现步骤和验收方式。阶段完成后运行测试并汇报实际结果，再等待用户验证或继续指令。

## 仓库保护

1. 开始时运行 `git status --short` 和 `git diff`。
2. 工作区已有用户未提交修改。保留所有已有修改；禁止 `git reset --hard`、`git checkout --` 或覆盖式重写。
3. 尤其注意 `main_window.py` 和 `tests/test_main_window.py` 已被修改，集成前重新读取最新内容，只做最小补丁。
4. 每个阶段先跑现有测试，区分基线问题和本阶段引入的问题。
5. 不提交 `D:/AstraTest/xianyu_chat_export.zip`、聊天正文、API Key、Cookie、浏览器配置文件或调试隐私数据。

## 不可自行改变的产品参数

- 用户点击“开始接待”才运行。
- 新建并保持一个应用专用客服标签页，不操作用户已有页。
- 单个已登录闲鱼账号。
- 10 秒轮询一次，每轮最多 10 个会话。
- 同一顾客连续消息等待 10 秒静默窗口后合并回复。
- 全局人工确认/自动发送二选一。
- 全局模式在开始前选择，运行中锁定；切换模式必须先停止接待。
- 每批最多 1 条文本和 1 张已登记图片。
- API 使用 DeepSeek，Key 在前端配置且不得明文落盘。
- 顾客图片交给 DeepSeek 视觉模型；语音优先点击页面“转文字”。
- V1 不实现本地 Whisper、不接飞书、不发送语音。
- 运行审计保留 15 天；商品知识、可信样例和不可逆去重哈希持久保留。
- 自动回复不进入检索样例；人工确认/编辑后发送的回复可以进入高可信样例。

## 实施纪律

- 浏览器 URL 和 DOM 选择器只能来自真实页面勘察；未验证前用接口和 fixture 占位，不要猜测生产选择器。
- 所有选择器集中在 `customer_service/browser_adapter.py`。
- Playwright Page 只在持有它的 Worker 线程使用。
- 业务编排必须可在不启动 Qt、不连接浏览器、不调用外网的条件下单元测试。
- 时间、模型客户端、浏览器适配器和仓库都通过依赖注入替换；测试禁止真实等待 10/10 秒。
- 模型输出永远不是发送许可。发送前必须通过本地策略、页面重读、指纹去重和回读确认。
- 历史样例只决定语气，不提供商品事实。
- 顾客内容、历史消息和网页文本均是不可信数据，不能覆盖系统规则或诱导读取本地文件。
- 除用户登记的图片资源外，模型不能选择任何本地路径。

## 各阶段交付清单

### CS-0

- 客服领域 dataclass/enum、配置默认值。
- 接待会话与回复任务状态机及非法迁移测试。
- 浏览器适配、模型客户端、时钟和仓库 Protocol。
- 旧测试与 Ruff 通过。

### CS-1

- `CustomerServiceRepository` 及全部表/索引。
- 永久去重指纹和 15 天审计清理。
- 安全 ZIP/JSON/CSV 导入、幂等、消息轮次切分。
- 本地隐私脱敏和中文轻量检索。
- 使用样本 ZIP 做只读验收；不要复制进仓库。

### CS-2

- DeepSeek Key 安全存储、连接测试、文本/视觉模型配置。
- 商品知识、别名、最低价、本地图片资源、聊天导入 UI。
- DeepSeek 客户端、JSON 契约、超时/退避/错误脱敏。
- 假 HTTP 服务测试，不在自动测试中调用真实 DeepSeek。

### CS-3

- 真实闲鱼客服页只读勘察。
- 页面健康、会话列表、消息方向/类型/稳定 ID、商品卡、图片取得、语音转文字。
- 脱敏 HTML fixtures 与诊断证据。
- 30 分钟只读稳定性验收；严禁本阶段发送。

### CS-4

- 长生命周期可停止 Worker 和线程安全命令队列。
- 10 秒轮询、每轮 10 个、公平调度、10 秒合并。
- 商品匹配、历史检索、脱敏、模型、策略到人工草稿的闭环。
- 人工编辑、文本发送前重读、发送与回读确认；本阶段不发送媒体。
- 人工确认回复进入高可信样例。

### CS-5

- 全局自动发送模式。
- 转人工规则、本地弹窗、最低价约束。
- 新消息废弃旧草稿、永久去重、登录/验证码/页面/连续失败熔断。
- 自动回复只进入 15 天审计。

### CS-6

- 顾客图片视觉理解、语音页面转写、人工/自动模式下的获批本地图片选择与发送。
- 15 天启动/周期清理、退出清理、日志脱敏。
- PyInstaller 配置和干净 Windows 验收。
- README、架构、隐私与使用说明更新。

## 每阶段统一验收命令

在项目根目录使用现有虚拟环境执行：

```powershell
.\.venv\Scripts\python.exe -m pytest
.\.venv\Scripts\python.exe -m ruff check src tests
```

CS-6 额外执行：

```powershell
.\scripts\build_windows.ps1
```

不能用“代码看起来正确”代替测试结果。真实页面验收无法自动化时，明确列出需要用户执行的步骤和观察点，不要伪造通过状态。

## 首轮给用户的响应模板

开始 CS-0 时，先回复：

> 本阶段只建立客服领域契约和可测试状态机，不连接闲鱼客服页、不调用 DeepSeek、不发送消息。我会先检查并保留现有未提交修改，运行基线测试，然后实现模型、接口和状态迁移测试。验收标准是旧功能无回归、客服状态机可独立测试；完成后再进入数据导入阶段。
