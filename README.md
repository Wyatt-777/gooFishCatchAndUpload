# 闲鱼铺货助手

Windows 本地桌面辅助工具，覆盖商品采集发布辅助与客服接待两条业务链：

1. 从获得授权的闲鱼卖家主页采集商品详情、图片和属性规格，并预填发布页；
2. 只读抓取当前账号的客服聊天，在本地整理商品知识、历史问答并生成待人工审核的回复草稿。

程序不会点击闲鱼最终发布按钮。客服消息默认人工审核；每次明确确认后可启用全自动模式。订单改价除本地规则外，还必须能核实实际订单金额及运费；无法核实时保留建议交由人工操作。

## 主要能力

- 搜索页发现商品链接，逐条读取详情页描述、售价、图片和属性规格；
- 下载商品图片并导出 Excel；
- 预填宝贝描述、本地图片、单一价格及完全匹配的属性选项；
- 区间价、类目和无法精确匹配的属性交由用户确认；
- 通过本机 CDP 连接已登录的 Chrome 或 Edge；
- 只读同步闲鱼客服会话，入库和发送给模型前执行隐私脱敏；
- 商品知识、历史问答和清洗知识库均保存在本地 SQLite；
- DeepSeek API Key 只保存到系统凭据存储，不写入数据库或日志；
- 客服回复默认进入人工审核队列；全自动模式每次启动都需确认，并保留会话重读、去重和转人工保护。
- 全自动模式采用适度主动销售：先回答顾客问题，再追加一个相关卖点或需求问题；顾客沉默30分钟后可在9:00–22:00追问一次，顾客或人工已回复时自动取消。
- “客服接待”的下单引导默认启用：议价成功或顾客明确想买、询问如何购买时，会在确认商品后提示点右上角“立即购买”、先取消付款并保留待付款订单，商家改好价格后再付款；对同一顾客连续触发会轮换措辞。普通问价与目录回复不触发这条下单提示，已下单或已付款不再提示拍下。人工审核模式可先检查草稿，全自动模式仍需启动确认。
- 客服数字先经过结构化语义分析和本地单位复核；型号、功率、续航、电压、容量、尺寸不会直接当作报价。发送前必须确认稳定会话ID、商品ID、消息批次和持久化会话版本一致。
- 真正的新顾客会话会在首轮回复开头发送已配置的话术；同一商家和顾客距上次询问满15分钟后提出新的问题，可再次发送话术并回答当前问题。15分钟内的追问正常回答且重新计时；收到、谢谢、单独补充型号或原问题重复不触发重发。已有订单、人工接管、身份不明或发送结果待核对时仍禁止发送接待话术；计时和发送记录在重启后保留。
- 长期顾客状态独立保存：记录生命周期、意向等级、销售/订单阶段、型号与续航需求、报价、跟进时间和人工接管状态；聊天正文过期清理后主档与状态事件仍保留，且不会仅凭同名昵称合并顾客。
- 闲鱼消息流出现平台“订单已签收”事件后，该订单会话停止模型回复、自动发送、改价和营销追问并转人工；已付款、待发货和运输中不触发。关闭提醒不会解除签收锁，只有人工明确选择“恢复该会话自动接待”才会恢复。
- 0.1.10将已发送并完成页面确认的成交价保存为下单凭据；顾客拍下待付款后直接生成改价任务。沿用右上角“修改价格”、金额与零运费输入、两次确认的既有操作，按待付款订单头部回读金额，必要时刷新后重新打开弹窗只读核对；活动标价不能代替订单价。订单编号缺失时绑定稳定的订单卡与商家、顾客、商品身份；已付款、退款、已人工改价或结果不确定时禁止重复提交。升级前缺少有效凭据的旧订单需人工核价，不回放历史订单。
- 0.1.9客服页面动作由隐藏执行进程隔离并设置总时限；超时后确认旧执行者退出再恢复。模型请求支持整体时限和取消，模型不可用时继续采集消息。质检ZIP包含运行参数、页面操作、恢复轨迹与执行者堆栈，便于另一台电脑反馈故障。

## 日常工作流

### 商品采集与发布辅助

1. 在“浏览器设置”启动或连接浏览器，并自行登录闲鱼；
2. 输入 `https://www.goofish.com/personal?userId=...` 格式的卖家主页；
3. 选择采集数量（1–100），开始采集；
4. 在商品表格检查详情并下载图片；
5. 点击“发布辅助”，检查预填结果后手动选择类目并决定是否发布。

### 客服知识与人工审核

1. 在“客服设置”配置 DeepSeek Base URL、模型名称和 API Key；
2. 点击“从当前账号抓取并整理”，只读同步已登录账号的聊天；
3. 可预览并导入普通聊天记录，或导入版本化的清洗知识库 JSON；
4. 在“客服接待”启动人工审核模式；
5. 检查草稿事实、价格和措辞后，再由人工确认后续操作。

下单引导随客服接待默认运行。可先用人工审核模式观察草稿，再按需选择全自动模式。

清洗知识库导入按文件 SHA-256 幂等处理，不会覆盖已有的非空人工商品事实；知识文档会保留来源会话和来源消息标识。

## 安装与开发运行

要求 Python 3.12 或 3.13：

```powershell
uv python install 3.12
uv venv --python 3.12
.\.venv\Scripts\Activate.ps1
uv pip install -e ".[dev]"
```

日常启动请双击项目根目录的 `Start-XianyuAssistant.vbs`，启动时只显示应用窗口，
不会额外打开命令行窗口。需要查看启动错误或调试输出时，才在终端运行：

```powershell
python -m xianyu_assistant.main
```

使用系统已安装的 Chrome 或 Edge；程序通过本机远程调试端口连接，不需要下载 Playwright 自带浏览器。

## 质量检查

```powershell
.\.venv\Scripts\python.exe -m pytest -q
.\.venv\Scripts\ruff.exe check src tests scripts
.\.venv\Scripts\python.exe -m compileall -q src scripts
```

## Windows 发布包

```powershell
.\scripts\build_windows.ps1
```

输出目录为 `dist\XianyuAssistant\`。将整个目录复制到目标 Windows 电脑，双击 `XianyuAssistant.exe` 运行。目标电脑仍需安装 Chrome 或 Edge，并在首次运行时登录闲鱼。

生成带当前业务数据库和离线运行依赖的安装程序：

```powershell
.\scripts\build_installer.ps1
```

输出为 `dist\XianyuAssistant-Setup-win64.exe`。安装程序自带 Microsoft Visual C++ x64 运行库和 Chrome 企业版 64 位离线安装程序；仅在目标系统缺失对应运行条件时安装。业务数据库只在目标数据目录不存在时初始化，升级、覆盖安装和卸载均不删除已有数据。API Key、浏览器登录资料、日志和数据库历史备份不会进入安装包。

本地数据库和日志默认位于 `%LOCALAPPDATA%\XianyuAssistant\`。应用“客服设置”页提供数据目录入口和过期审计记录清理按钮。
安装程序会附带构建时的完整应用数据库和仍在本机的商品图片，在新用户首次启动时导入其数据目录；已有数据库不会被覆盖。API Key 和浏览器登录资料不进入安装程序，须在目标电脑重新配置和登录。

详细安装、验收与数据安全说明见 [用户操作与交付说明](docs/用户操作与交付说明.md)。
