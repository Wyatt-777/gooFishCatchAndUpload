# 闲鱼铺货助手 V1.0 技术架构设计

版本：v1.0

目标：

设计一个 Windows 桌面自动化工具，实现闲鱼商品采集与发布辅助。

------------------------------------------------------------------------

# 1. 总体架构

采用本地桌面应用架构：

    用户
     |
    Windows Desktop App
     |
    +----------------------+
    | PyQt6 UI             |
    +----------------------+
              |
    +----------------------+
    | 业务逻辑层            |
    | Task Manager         |
    | Product Manager      |
    +----------------------+
              |
    +----------------------+
    | 自动化层              |
    | Playwright           |
    +----------------------+
              |
    Chrome / Edge
              |
    闲鱼网页

------------------------------------------------------------------------

# 2. 技术选型

## 开发语言

Python 3.12+

原因：

-   浏览器自动化生态成熟
-   打包简单
-   适合快速商业交付

## GUI框架

PyQt6

负责：

-   窗口
-   表格
-   按钮
-   任务管理

## 浏览器自动化

Playwright

负责：

-   控制Chrome/Edge
-   页面访问
-   元素操作
-   数据提取

## 本地数据库

SQLite

保存：

-   任务状态
-   商品数据
-   用户配置

## Excel处理

openpyxl

负责：

-   商品导出

## 打包

PyInstaller

输出：

    XianyuAssistant.exe

------------------------------------------------------------------------

# 3. 项目模块设计

## UI模块

负责：

-   主窗口
-   任务创建
-   商品列表
-   设置页面

------------------------------------------------------------------------

## Browser Manager

职责：

管理浏览器连接。

功能：

-   启动浏览器
-   连接用户环境
-   保持登录状态

------------------------------------------------------------------------

## Task Manager

职责：

管理采集任务。

数据：

    task_id
    keyword
    status
    created_time
    progress

支持：

-   创建
-   暂停
-   恢复
-   完成

------------------------------------------------------------------------

## Crawler模块

职责：

采集闲鱼商品。

输入：

关键词。

输出：

商品对象。

------------------------------------------------------------------------

## Product模块

商品数据结构：

    Product

    id

    title

    price

    description

    category

    url

    images

    status

------------------------------------------------------------------------

## Image Manager

职责：

下载并管理图片。

功能：

-   图片下载
-   文件分类
-   路径管理

------------------------------------------------------------------------

## Publisher模块

职责：

发布辅助。

功能：

-   打开发布页面
-   填写字段
-   上传图片

最终：

停止等待用户确认。

# 5. 开发原则

## 原则1

先保证采集稳定。

不要优先开发自动发布。

------------------------------------------------------------------------

## 原则2

所有自动化操作必须有异常处理。

例如：

-   页面不存在
-   网络失败
-   元素变化

------------------------------------------------------------------------

## 原则3

模块之间保持低耦合。

未来可以替换：

-   AI模块
-   浏览器模块
-   数据模块
